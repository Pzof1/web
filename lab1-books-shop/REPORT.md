# Отчёт по лабораторной работе 1

## Тема

Разработка интернет-магазина с каталогом книг, корзиной покупок и формой заказа.

## Цель работы

Я создал адаптивную страницу магазина на HTML, CSS и чистом JavaScript. По заданию пользователь должен просматривать каталог, добавлять товары в корзину, менять их количество, видеть актуальную сумму и оформлять заказ с контактными данными.

## Ход работы

Я вёл работу небольшими коммитами в ветке `feat/web-labs`, чтобы история отражала последовательность разработки. До финального шага в ветке уже были отдельные этапы: семантический каркас магазина, карточки каталога и счётчик, затем интерактивная корзина с сохранением. В финальном шаге я добавил форму заказа с именем, фамилией, адресом и телефоном, проверку обязательных полей средствами HTML и JavaScript и сообщение об успешном создании заказа.

После успешной отправки корзина очищается, а пустое состояние сохраняется. Я также дополнил README и подготовил этот отчёт вместе с отдельной инструкцией для защиты.

## Реализованные возможности

- Каталог строится из массива книг в отдельном файле.
- Карточки показывают обложку, жанр, название, автора и цену.
- Книга добавляется в корзину; количество можно увеличить или уменьшить, позицию можно удалить.
- Счётчик, стоимость позиции и общая сумма пересчитываются при изменениях.
- Корзина хранится в `localStorage` и восстанавливается после загрузки страницы; неизвестные товары и некорректные количества при восстановлении отбрасываются.
- Кнопка оформления открывает форму с четырьмя обязательными полями.
- HTML ограничивает длину и допустимые символы имени и фамилии, проверяет обязательность и длину адреса и формат телефона. JS обрезает пробелы по краям и дополнительно проверяет, что в номере от 10 до 15 цифр.
- После корректной отправки появляется сообщение «Заказ создан!», форма закрывается, корзина очищается.
- Адаптивная компоновка использует CSS Grid, Flexbox и медиазапросы.

## Проверка

Перед сдачей я выполню следующий браузерный сценарий и впишу фактический результат после прохождения каждого пункта:

1. Загрузить страницу, проверить каталог и пустую корзину.
2. Добавить одну книгу несколько раз и проверить счётчик, количество и итоговую сумму.
3. Перезагрузить страницу и проверить восстановление корзины; уменьшить количество, удалить одну позицию и затем последнюю.
4. Открыть оформление, отправить пустую форму, затем проверить недопустимые имя/фамилию, адрес и слишком короткий телефон.
5. Ввести корректные данные, создать заказ и убедиться, что форма закрылась, корзина очистилась и пустое состояние переживает перезагрузку.
6. Проверить каталог и корзину на настольной и мобильной ширине.

В этой среде визуальный прогон браузера не выполнен; пункты выше не отмечены как пройденные. Код не отправляет заказ на сервер: оформление демонстрационное и клиентское.

## Ответы для защиты

**Как формируется каталог?**

Данные хранятся в `js/data.js`. Скрипт перебирает массив, создаёт элементы DOM и добавляет их в контейнер каталога.

**Как устроена корзина?**

В памяти используется `Map`, где ключ — идентификатор книги, значение — количество. При каждом действии интерфейс строится заново из текущего состояния, а сумма вычисляется как сумма цены каждой книги, умноженной на её количество.

**Зачем нужен `localStorage`?**

Он сохраняет сериализованные пары «идентификатор — количество» между перезагрузками браузера. При восстановлении приложение сверяет идентификаторы с каталогом и пропускает некорректные данные.

**Как проверяется форма?**

HTML задаёт обязательность, длину и шаблон допустимых символов. Обработчик JS убирает внешние пробелы, проверяет validity каждого поля и отдельно считает цифры в телефонном номере.

**Что происходит после оформления?**

Страница показывает «Заказ создан!», сбрасывает и скрывает форму, очищает корзину и сохраняет пустое состояние. Серверной отправки в этой версии нет.

**Почему не использованы библиотеки?**

В задании рекомендуется чистый HTML, CSS и JavaScript; интерфейс реализован без CSS- и JS-фреймворков.

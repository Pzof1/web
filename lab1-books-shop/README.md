# Лабораторная 1 — книжный магазин

Статический книжный магазин на семантическом HTML, CSS Grid/Flexbox и vanilla JavaScript. Карточки каталога строятся из отдельного набора данных, а кнопка добавления обновляет количество товаров в корзине.

## Запуск

Откройте `index.html` в браузере или запустите из этой папки локальный сервер:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Структура

- `index.html` — семантическая структура страницы.
- `css/styles.css` — оформление и адаптивная сетка.
- `js/data.js` — каталог книг.
- `js/app.js` — построение карточек и добавление книг в корзину.
- `assets/` — favicon и локальные иллюстрации обложек.

На текущем этапе доступны карточки, цены, добавление книги и общий счётчик корзины. Удаление книг, изменение количества, итоговая сумма, сохранение корзины и полная форма заказа относятся к следующим этапам.

# Лабораторная 1 — книжный магазин

Статическая основа адаптивного книжного магазина на HTML, CSS и JavaScript без фреймворков.

## Запуск

Откройте `index.html` в браузере или запустите из этой папки локальный сервер, например:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Структура

- `index.html` — семантическая структура страницы.
- `css/styles.css` — оформление и адаптивная сетка.
- `js/data.js` — отдельный каталог книг.
- `js/app.js` — построение карточек каталога.
- `assets/` — favicon и локальные иллюстрации обложек.

Этап 1 задаёт основу интерфейса. Интерактивная корзина и оформление заказа добавляются в следующих этапах.

# Лабораторная 1 — книжный магазин

Адаптивный книжный магазин «Лист» с каталогом, корзиной и клиентской формой заказа. Приложение использует семантический HTML, CSS Grid/Flexbox и чистый JavaScript без фреймворков.

## Реализовано

- Каталог строится из массива книг в `js/data.js`; у каждой книги есть локальная SVG-обложка.
- Корзина поддерживает добавление книг, изменение количества, удаление позиций, подсчёт числа экземпляров и общей суммы.
- Содержимое корзины сохраняется в `localStorage` и восстанавливается после перезагрузки.
- Форма заказа содержит поля имени, фамилии, адреса и телефона. Проверяются обязательность, допустимая длина, символы и число цифр телефона.
- После успешной проверки показывается сообщение о создании заказа, форма скрывается, корзина очищается. Заказ остаётся демонстрационным и не отправляется на сервер.
- Каталог, корзина и форма адаптируются к планшетной и мобильной ширине. На странице есть ссылка возврата на главную.

## Файлы проекта

- `index.html` — семантическая разметка страницы и формы.
- `css/styles.css` — визуальное оформление и адаптивная раскладка.
- `js/data.js` — данные книг и пути к обложкам.
- `js/app.js` — каталог, корзина, хранение состояния и проверка заказа.
- `assets/` — четыре обложки и favicon.
- `REPORT.md` и `DEFENSE.md` — отчёт по работе и материал для защиты.

## Запуск

Из этой папки:

```sh
python3 -m http.server 8000
```

Приложение открывается по адресу <http://localhost:8000> и опубликовано на [GitHub Pages](https://pzof1.github.io/web/lab1-books-shop/).

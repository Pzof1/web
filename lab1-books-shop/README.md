# Лабораторная 1 — книжный магазин

Статический книжный магазин на семантическом HTML, CSS Grid/Flexbox и vanilla JavaScript. Каталог строится из отдельного набора данных. Корзина поддерживает добавление, изменение количества, удаление, автоматический пересчёт общей суммы и сохранение в `localStorage`.

## Запуск

Откройте `index.html` в браузере или запустите из этой папки локальный сервер:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Структура

- `index.html` — семантическая структура страницы.
- `css/styles.css` — оформление и адаптивная сетка.
- `js/data.js` — каталог книг.
- `js/app.js` — построение карточек и добавление книг в корзину.
- `assets/` — favicon и локальные иллюстрации обложек.

На текущем этапе доступны карточки, цены, управление корзиной и восстановление после перезагрузки. Следующий этап — форма оформления заказа с именем, фамилией, адресом доставки и контактным телефоном; после отправки показывается подтверждение создания заказа.

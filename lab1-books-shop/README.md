# Лабораторная 1 — книжный магазин

Адаптивный каталог книжного магазина на семантическом HTML, CSS Grid/Flexbox и vanilla JavaScript. Каталог строится из отдельного набора данных. Корзина поддерживает добавление книг, изменение количества, удаление, пересчёт суммы и сохранение в `localStorage`. Кнопка «Оформить заказ» открывает форму с именем, фамилией, адресом доставки и телефоном; перед созданием заказа проверяются поля и формат номера.

## Запуск

Откройте `index.html` в браузере или из этой папки запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Перейдите на `http://localhost:8000`.

## Структура

- `index.html` — семантическая разметка каталога, корзины и формы заказа.
- `css/styles.css` — оформление, сетки и адаптация для планшета и телефона.
- `js/data.js` — данные каталога.
- `js/app.js` — карточки, корзина, localStorage и валидация заказа.
- `assets/` — favicon и локальные SVG-обложки.
- `REPORT.md` — отчёт о ходе работы, устройстве проекта и вопросах для защиты.
- `DEFENSE.md` — порядок демонстрации и список вопросов для подготовки.

## Возможности и проверки перед сдачей

Каталог и корзина работают без JS-фреймворков. Форма использует ограничения HTML (`required`, длина, `pattern`) и дополнительную JavaScript-проверку: телефон должен содержать от 10 до 15 цифр. При успешной отправке выводится «Заказ создан!», корзина очищается и сохранённое состояние обновляется.

Перед сдачей откройте приложение в браузере и пройдите сценарии из раздела «Проверка» в [отчёте](REPORT.md), включая мобильную ширину, сохранение корзины и форму заказа. В отчёте следует отметить только фактически выполненные проверки; сценарий показа собран в [DEFENSE.md](DEFENSE.md).

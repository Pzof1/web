# Web programming labs

Two independent student projects for the Web Programming course:

- `lab1-books-shop/` — responsive book shop with a working cart and order form.
- `lab2-todo/` — task manager built with plain JavaScript and DOM APIs.

Both projects use HTML, CSS, and vanilla JavaScript. The work follows the written lab requirements and the instructor's shared review notes: keep assets organized, include a README and favicon, avoid `innerHTML` for building elements, and leave out test dialogs and unused code.

## Work plan

Each lab will be developed in small, reviewable milestones on one feature branch. The scheduled work is planned for Sunday and Monday, with one meaningful commit per lab on each day. After implementation, both projects will be reviewed, the commit history checked, and the feature branch merged into `main` once.

## Projects

The individual lab READMEs will document how to run each project, its features, and what to demonstrate during the defense.

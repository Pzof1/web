# Лабораторная работа 3 — 2048

Браузерная игра 2048 на HTML, CSS и чистом JavaScript без JS- и CSS-фреймворков. Игровое поле 4×4 поддерживает стрелки клавиатуры, экранные кнопки и свайпы. После успешного хода появляются новые плитки; одинаковые значения объединяются, а счёт увеличивается на значение объединённой плитки.

Партия и возможность отмены последнего хода сохраняются в `localStorage`. После окончания игры можно записать имя и результат; таблица показывает до десяти лучших результатов с датой. Новую партию можно начать без перезагрузки страницы.

## Запуск

Откройте опубликованную [игру](https://pzof1.github.io/web/lab3-2048/) или запустите сервер из корня репозитория:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000/lab3-2048/`. Состояние хранится в браузере и доступно при повторном открытии с того же origin.

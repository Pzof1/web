## Цель

Создать адаптивную браузерную игру 2048 на чистых HTML, CSS и JavaScript: реализовать ходы, слияние плиток, подсчёт очков, конец игры, отмену, сохранение сессии и таблицу лидеров.

## Ход работы

1. Подготовлена адаптивная HTML-страница с полем 4×4, счётом, кнопками управления и диалогом завершения партии.
2. Реализована игровая логика перемещения во всех направлениях, однократного слияния плитки за ход, начисления очков и проверки доступности ходов.
3. Добавлены управление клавиатурой, экранные кнопки и свайпы, а также визуальные состояния плиток и анимации.
4. Добавлены сохранение и восстановление партии через `localStorage`, отмена предыдущего хода, запись результата и отображение топ-10.
5. В рамках выпуска подготовлена документация лабораторной, а корневая страница дополнена ссылкой на игру. Игровой код при этой проверке не менялся: подтверждённых дефектов в просмотренной реализации не обнаружено.

## Проверка требований

Реализация использует чистый JavaScript без React и других JS-фреймворков. Реализованы все функции из постановки: управление полем, сохранение рекорда, просмотр лидеров, продолжение сессии, отмена последнего хода и перезапуск. Дизайн сверялся с предоставленным примером 2048 как с визуальным ориентиром.

# Лабораторная 2 — ToDo

Базовая страница списка задач на чистом JavaScript и DOM API. HTML содержит только каркас документа и подключения CSS/JS; интерфейс создаётся в `js/app.js`.

## Запуск

Из корня проекта запустите локальный сервер:

```sh
cd lab2-todo
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

## Текущий этап

- Рендер пустого списка и созданных задач.
- Добавление задачи с названием и датой, с проверкой полей.
- Редактирование названия и даты задачи.
- Отметка задачи как выполненной и удаление.
- Сортировка списка по дате после создания и изменения задачи.
- Сохранение задач в `localStorage` и восстановление при загрузке страницы.
- Адаптивная базовая раскладка и семантические элементы создаются скриптом.

Поиск, фильтрация и перетаскивание задач остаются для следующих этапов.

## Технологии

Vanilla JavaScript, DOM API и CSS без фреймворков.

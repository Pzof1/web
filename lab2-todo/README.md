# Лабораторная 2 — ToDo

Приложение ToDo на чистом JavaScript и DOM API по [исходному заданию](https://github.com/Dasha2101/WEB2025Q26LB2). CSS- и JavaScript-фреймворки не используются.

## Реализовано по заданию

- Создание задачи с названием и датой, редактирование названия/даты, удаление и отметка выполнения с визуальным состоянием.
- Сортировка по дате по возрастанию и убыванию.
- Поиск по названию и дате: поддерживаются фрагменты отображаемой даты и дата в формате `YYYY-MM-DD`.
- Фильтр всех, выполненных и невыполненных задач.
- Ручная перестановка drag-and-drop в режиме «Вручную». Она доступна для полного списка без активного поиска/фильтра и выключена в режимах сортировки по дате; после перестановки порядок сохраняется.
- Задачи и порядок хранятся в `localStorage` под ключом `webprog-labs-todo-tasks` и восстанавливаются при загрузке.
- Интерфейс строится скриптом через семантические DOM-элементы и методы `append`; текст и атрибуты задаются через DOM API. HTML содержит только базовую оболочку и подключения ресурсов.
- Адаптивная раскладка реализована в CSS Grid/Flexbox. На странице есть ссылка возврата на главную.

## Файлы проекта

- `index.html` — базовая оболочка документа и подключения CSS/JavaScript.
- `js/app.js` — создание интерфейса, операции с задачами, поиск, фильтр, сортировка и хранение.
- `css/styles.css` — оформление интерфейса и мобильная раскладка.
- `assets/favicon.svg` — значок страницы.
- `REPORT.md` и `DEFENSE.md` — отчёт по работе и материал для защиты.

## Запуск

Из этой папки:

```sh
python3 -m http.server 8000
```

Приложение открывается по адресу <http://localhost:8000> и опубликовано на [GitHub Pages](https://pzof1.github.io/web/lab2-todo/).

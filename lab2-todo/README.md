# Лабораторная 2 — ToDo

Список задач на чистом JavaScript и DOM API. Каркас документа подключает CSS и JavaScript, а поля, фильтры, список, кнопки и остальные элементы интерфейса создаются скриптом.

## Запуск

Из этой папки запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Также приложение опубликовано по адресу <https://pzof1.github.io/web/lab2-todo/> после успешного запуска GitHub Pages workflow.

## Возможности

- Добавление задачи с названием и корректной календарной датой.
- Изменение названия и даты, отметка выполнения и удаление.
- Поиск по названию и фильтр «Все задачи / Невыполненные / Выполненные».
- Сортировка по дате в прямом или обратном порядке.
- Ручное перетаскивание строк мышью в режиме «Вручную». Для изменения общего порядка нужно очистить поиск и выбрать фильтр «Все задачи».
- Сохранение массива задач и его ручного порядка в `localStorage` под ключом `webprog-labs-todo-tasks`; восстановление после перезагрузки.
- Адаптивный интерфейс на CSS Grid и Flexbox, без библиотек и фреймворков.

## Структура

- `index.html` — базовая HTML-оболочка и подключения CSS/JS; содержимое интерфейса не размечено вручную.
- `js/app.js` — создание DOM, модель задач, фильтрация, сортировка, drag-and-drop и `localStorage`.
- `css/styles.css` — оформление и адаптивная раскладка с классами, заданными скриптом.
- `assets/favicon.svg` — значок вкладки.
- `REPORT.md` — ход работы, устройство, проверки и места для собственных скриншотов.
- `DEFENSE.md` — запуск, показ ключевых частей и вопросы для подготовки.

## Проверка перед сдачей

В браузере проверьте добавление, редактирование, удаление, отметку выполнения, поиск, все состояния фильтра, обе сортировки по дате, перетаскивание мышью и восстановление ручного порядка после перезагрузки. Полный сценарий с ожидаемыми результатами записан в [отчёте](REPORT.md).

# Защита лабораторной 2: ToDo

## Запуск

1. Перейти в `lab2-todo/`.
2. Выполнить `python3 -m http.server 8000`.
3. Открыть <http://localhost:8000>.
4. Для чистого показа удалить ключ `webprog-labs-todo-tasks` из DevTools → Application → Local Storage или очистить данные сайта.

## Порядок показа

1. Показать пустой список и пояснить, что HTML задаёт каркас, а элементы интерфейса создаёт `js/app.js`.
2. Создать несколько задач с разными датами; показать проверку обязательных полей.
3. Изменить название и дату одной задачи, затем показать отмену редактирования.
4. Отметить задачу выполненной и показать визуальное состояние; проверить фильтры «Все задачи», «Невыполненные» и «Выполненные».
5. Найти задачу по фрагменту названия, очистить строку поиска и показать пустой результат для запроса без совпадений.
6. Включить сортировку сначала по ранним, затем по поздним датам.
7. В настольном браузере выбрать «Вручную», мышью перетащить задачу выше или ниже, перезагрузить страницу и показать восстановленный порядок.
8. Удалить задачу и показать обновлённый счётчик.
9. Показать адаптивную раскладку на мобильной ширине.

## Ключевые части кода

- `loadTasks` проверяет сохранённые записи и восстанавливает порядок массива.
- `createElement` и `renderTasks` создают DOM-элементы без сборки HTML-строк.
- `getVisibleTasks` применяет поиск, статусный фильтр и сортировку по дате.
- `commitVisibleOrder` сохраняет ручной порядок полного списка.
- `saveTasks` и `localStorage` сохраняют состояние между загрузками.
